# Project Statement

## Problem Statement

Students usually have a lot of things to remember, such as assignments, exams, projects, and different deadlines. When there are several tasks at the same time, it is easy to forget something or lose track of what has already been completed.

The Student Task Manager is a simple application that helps solve this problem. It gives students one place to add their tasks and check their progress. They can easily see which tasks are still pending and which ones have been completed.

## Scope of the Project

This project is a Java-based console application mainly designed for managing student tasks.

A user can add a task by entering its title, due date, and category. The user can then view the saved tasks, mark a task as completed, or delete it if it is no longer required.

The program also stores the tasks in a local file. This means the tasks are not lost when the program is closed and opened again. It also provides some basic statistics, such as the total number of tasks, completed and pending tasks, completion percentage, and tasks based on their categories.

For now, the project is limited to a command-line interface. It does not include features such as a graphical interface, online databases, or separate user accounts.

## Target Users

The main target users are students who need a simple way to organize their academic work.

The application can be useful for:

- College and university students
- Students who have several assignments to manage
- Students preparing for exams
- Anyone who wants a simple way to keep track of personal tasks

The program is designed to be straightforward, so users can use it without needing any technical knowledge.

## High-Level Features

The main features included in the project are:

- **Add Tasks** – Add a new task by entering its title, due date, and category.
- **View Tasks** – See all the tasks along with their due dates, status, and category.
- **Mark as Completed** – Change a task from pending to completed.
- **Delete Tasks** – Remove tasks that are no longer required.
- **Task Categories** – Keep tasks organized using categories such as assignments and exams.
- **Save Tasks** – Store tasks in a local file so they are available the next time the program is opened.
- **Basic Analytics** – Show information such as total tasks, pending tasks, completed tasks, completion rate, and category-wise task count.
- **Error Handling** – Deal with invalid task IDs and incorrect inputs without causing the program to stop unexpectedly.
